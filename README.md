# Software Engineering Interview Preparation - 14 Days Plan

This repository contains a 14-day study plan to prepare for Software Engineering interviews, covering Data Structures & Algorithms (DSA), System Design, and Behavioral interviews. It includes:

- A detailed daily schedule (`schedule.md`)
- Curated resources for each topic (`resources.md`)
- A list of 20 LeetCode problems to solve (`problems_list.md`)
- Solutions to each problem in Python, organized by day (`day01/` through `day14/`)

## How to Use

1. Follow the daily schedule in `schedule.md`.
2. For each day, solve the assigned LeetCode problems.
3. Refer to the solution files for reference or if you get stuck.
4. Use the resources in `resources.md` for additional learning.
